evaluator が計画 Issue に追記した最新のレビューコメントを訂正してください。

引数: `<計画 Issue 番号>` [訂正内容（省略可）]

## 手順

### 1. 最新の Review Attempt コメントを取得する

```bash
gh issue view <計画 Issue 番号> --comments --json comments \
  --jq '[.comments[] | select(.body | startswith("## Review Attempt"))] | last | {url: .url, body: .body}'
```

Review Attempt コメントが存在しない場合は「evaluator のレビューコメントが見つかりません」と報告して終了する。

### 2. 訂正内容を確認する

- 引数に訂正内容が含まれている場合: それをそのまま使う
- 含まれていない場合: 現在のコメント本文を表示し「どの部分をどう変更しますか？」と聞く
- 訂正指示が曖昧な場合は「この解釈でよいですか？」と確認してから進む

### 3. evaluator エージェントに委譲する

このレビューコメントを書いたのは `@evaluator` なので、訂正も同じエージェントに依頼する。
再評価はさせず、訂正内容をそのまま反映させるだけであることを明示する。

以下の情報をすべてプロンプトに含めて `@evaluator` に渡す。

- コメント URL
- 現在のコメント本文全体
- ユーザーが指示した訂正内容（具体的に）
