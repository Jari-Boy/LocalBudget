セッションを開始します。

## 手順

### 1. マージ済みブランチの整理

`/branch-cleaner` スキルを実行する。

### 2. 現状確認

```bash
git status
git branch
```

未コミットの変更やブランチが残っている場合は処理方針をユーザーに確認する。

### 3. Issue の作成・計画

`/issue` を実行する（= `@planner` が Issue を作成）。

ユーザーが取り組む内容を伝えたら planner に渡す。既存 Issue がある場合はその番号を渡す。

### 4. ブランチ作成

計画 Issue がユーザーに承認されたらブランチを作成する。

```bash
git checkout -b feature/issue-<番号>-<概要>
```

### 5. 実装・評価ループの開始

`/develop <計画 Issue 番号>` を実行する。

## 注意事項

- 未コミットの変更がある場合は先に処理方針を確認する
- ブランチは計画 Issue 承認後に切る
