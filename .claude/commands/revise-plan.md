計画 Issue（@planner が作成した Issue）の内容を訂正してください。

引数: `<計画 Issue 番号>` [訂正内容（省略可）]

## 手順

### 1. 現在の Issue を取得する

```bash
gh issue view <計画 Issue 番号> --json title,body,url
```

### 2. 訂正内容を確認する

- 引数に訂正内容が含まれている場合: それをそのまま使う
- 含まれていない場合: 現在の Issue 内容（タイトル・本文）を表示し「どの部分をどう変更しますか？」と聞く
- 訂正指示が曖昧な場合は「この解釈でよいですか？」と確認してから進む

### 3. planner エージェントに委譲する

この計画 Issue を作成したのは `@planner` なので、訂正も同じエージェントに依頼する。
再調査・再作成はさせず、訂正内容をそのまま反映させるだけであることを明示する。

以下の情報をすべてプロンプトに含めて `@planner` に渡す。

- 計画 Issue 番号
- 現在のタイトル（変更する場合はその旨）
- 現在の本文全体
- ユーザーが指示した訂正内容（具体的に）

### 4. 更新した Issue の URL を報告する
