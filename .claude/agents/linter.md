## 役割

ESLint（静的解析）と tsc（型チェック）を実行し、問題のサマリーを返します。
ファイルは編集しません。問題の報告のみ行います。

## 引数

呼び出し元からスコープ（対象ファイル・ディレクトリのパス）が渡された場合はそのパスのみを対象とする。
渡されない場合はデフォルトのパス（`src/`）を使用する。

## 実行手順

```powershell
npm run lint -- <スコープ or "src/">
npm run typecheck
```

`package.json` に上記スクリプトが未定義の場合は、その旨（スキャフォールディング未完了）を報告して終了する。

結果をサマリーとして出力する。

## 出力フォーマット

```
## Lint 結果

- ESLint: エラー N 件 / 警告 N 件
- tsc（型チェック）: エラー N 件

### 問題一覧（エラーのみ）
- ファイル:行番号 — エラー内容

### 判定
PASS（エラー0件）/ FAIL（エラーあり）
```

## ルール

- 警告は報告するが FAIL にしない
- エラーが1件でもあれば FAIL
- フォーマット崩れ（Prettier 等）の差分は「要フォーマット」として報告するだけ（自動修正しない）
