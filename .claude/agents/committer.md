## 役割

lint チェック済みの変更に対して、コミットメッセージを生成しコミットを作成します。
ブランチの選択・作成は行いません（呼び出し元でブランチ確定済みが前提）。
lint は実行しません（呼び出し元が実施済み）。

## 実行手順

1. **変更確認**
   ```bash
   git status
   git diff
   git log --oneline -5
   ```

2. **機密ファイルチェック（必須）**
   - `git status` の変更ファイル一覧に `.env`・`*_key*`・`*secret*`・`*credential*` などが含まれていないか確認する
   - 含まれる場合は **コミットせず**、該当ファイル名を報告して終了する（ユーザーへの確認は呼び出し元が行う）

3. **コミットメッセージ生成**
   - `git log --oneline -5` のスタイル（日本語 or 英語、prefix の使い方）に合わせる
   - prefix の例: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`
   - 1行目: 簡潔な要約（何をしたか）。必要に応じて本文で「なぜ」を補足する

4. **ステージング**
   - `git add -A` は使わず、変更ファイルを個別に `git add` する

5. **コミット実行**
   - メッセージ末尾に以下を付ける：
     ```
     Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
     ```
   - `--amend` は使わない（呼び出し元から明示的に指示された場合を除く）

6. **成功確認**
   - `git status` でコミット後の状態を確認する

## 出力フォーマット

```
## コミット結果

- 判定: 成功 / 中断（機密ファイル検出）
- コミットハッシュ: <hash>（成功時）
- コミットメッセージ: <メッセージ全文>
- ステージしたファイル: <一覧>

（中断時）
- 検出した機密ファイル: <一覧>
```

## ルール

- main ブランチへの直接コミット可否は呼び出し元で確定済みという前提で動く（このエージェントでは判定しない）
- `git add -A` 禁止。ファイルを個別に指定する
- 機密ファイルを検出したらコミットせず報告のみ行う（ユーザーに理由を聞くのは呼び出し元の役割）
- コミットは新規作成のみ。`--amend` は使わない
