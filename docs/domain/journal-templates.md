## 1. 仕訳テンプレート

### 1.1 位置づけ

仕訳テンプレートは、よく使う仕訳の「ひな形」である。摘要・起票者・明細行(科目・借方/貸方・金額・取引先・プロジェクト・世帯メンバー・精算バッチ)を保存しておき、起票時に「新規仕訳」フォームへ展開する。

[定期仕訳](./recurring-transactions.md#11-位置づけ)との違いは、**繰り返し周期・提案を持たない**ことである。定期仕訳は周期に従って仕訳の提案・生成を行うが、テンプレートは利用者が選んだときにフォームを埋めるだけで、仕訳(`journal_entries`)も下書き(`journal_entry_drafts`)も参照・作成しない。

管理は仕訳画面の「テンプレート」タブで行う(マスタ画面ではない。判断は[decisions.md](../decisions.md) 2026-11-15)。見た目は仕訳一覧・仕訳の入力欄と同じで、左の一覧は仕訳一覧と同じカード型(名称・右に金額・下に内容・無効のタグ)、右パネルは仕訳の入力欄(`JournalEntryEditor`)を、テンプレートが持たない取引日とコメントを隠して使う。

### 1.2 グループ・並び順

取引先([counterparties.md](./counterparties.md))・プロジェクト([projects.md](./projects.md))と同じ仕様のグループ(`journal_template_groups`)を持ち、グループ付きのツリー(カード型の一覧)で管理する。

- 入れ子可・単一所属(1つのテンプレートが所属できるグループは1つ)・表示専用(集計には関与しない)。`category`は持たない。
- 子グループまたは所属するテンプレートがある(中身のある)グループは削除できない(DDLトリガーで強制)。
- `sort_order`は、同じ入れ物の中でサブグループと直属のテンプレートが1つの表示順を共有する。
- 並び順は手動(カードのドラッグ、右パネルの「上へ/下へ」・所属グループの選択)で決め(複数選択はない)、その並びが「テンプレートから起票」の一覧の並びになる。「よく使う順」の自動並びは採らない(将来の拡張候補)。

### 1.3 ライフサイクル

- 名称(`name`)は**全テンプレートで一意**(無効のものを含む)。
- **削除と無効化の両方ができる**。仕訳はテンプレートを参照しないため、削除は常に可能である。
- 無効なテンプレートは、起票ダイアログの一覧に出ない。

### 1.4 行の制約

行(`journal_template_lines`)は、2行のテンプレートも3行以上のテンプレートも同じ表で表す。

- **2行以上・借方と貸方がそれぞれ必要**。
- **科目は空(NULL)の行も保存できる**。「テンプレートを追加」は、科目も金額も空の借方・貸方の2行で作る(利用者が選んでいない科目を仮に入れない)。画面の保存は、科目が決まっていること・金額の検証を、変更があるときに求める(科目を選ぶまで摘要・金額・行は保存できず、名称だけ保存できる)。科目が空の行は、起票時も科目が空のまま展開される(警告は出さない。確定は既存の入力チェックで止まる)。
- **金額は行単位で空欄(NULL=起票時に入力)か正の整数**。**全行の金額があるときだけ**、Repositoryが貸借の一致を検証する([journal.md 1.3](./journal.md#13-貸借バランスの検証)と同じ`assertJournalBalance`)。1行でも空欄があれば検証しない(起票時の通常の検証に委ねる)。
- **取引先は収益・費用の科目の行だけ**に設定できる(DDLトリガー。[counterparties.md 1.2](./counterparties.md)・`journal_lines`と同じ)。
- **精算バッチは、システム管理の立替金・未払金の科目の行だけ**に設定できる(Repositoryが検証、`journal_lines`と同じ)。
- **世帯メンバーがNULL=行では決めない**。起票時に「科目の既定メンバー > 行の指定 > 起票者」の順で決まる([household-members.md 1.2](./household-members.md#12-紐づけ対象と明細行の世帯メンバーの決め方))。
- **起票者がNULL=起票時に選ぶ**。行の世帯メンバーとは別の概念。

### 1.5 起票の流れ

1. 仕訳画面ヘッダーの「テンプレートから起票」を押すと、モーダルのダイアログが開く。**ダイアログを開く時点でテンプレートを読み直す**(別タブでの追加・編集を反映するため)。
2. 一覧は有効なテンプレートだけを、マスタの並び順とグループ見出しのまま表示する。検索は名称・摘要・科目名・取引先名のAND(スペース区切り)で、全角半角・大文字小文字を区別しない。上下キー・Enterで選択、Escapeで閉じる。フォーカストラップを持つ。
3. テンプレートを選ぶと、**下書きを作らず**、既存の「新規仕訳」フォーム(selection kind=`new`)へ展開する。日付は今日、摘要はテンプレートの摘要、コメントは空、金額の空欄は空文字。入力途中の内容があれば、既存の未保存警告(`useUnsavedEditGuard`系)を通してから展開する。
4. 無効な(または存在しない)科目・取引先・プロジェクト・世帯メンバーは、不正な値を入れず空にして警告を出す。科目が空の行は、既存の入力チェックで確定できない。
5. 確定は通常の新規仕訳と同じ経路(`JournalEntryRepository`、貸借検証あり)である。テンプレートと仕訳の関係は保持しない。

展開の純粋関数は`expandJournalTemplate`、一覧の検索・グルーピングは`listTemplatePickerItems`にある。

## 2. 仕訳テンプレートマスタ(journal_templates・journal_template_lines)

### 2.1 フィールド定義

**journal_templates**

| フィールド | 説明 | 制約 |
|---|---|---|
| `id` | テンプレートID | PK |
| `name` | 名称 | UNIQUE(無効も含む) |
| `memo` | 起票時の摘要の初期値 | 任意 |
| `bookkeeper_household_member_id` | 起票者の初期値 | FK(`household_members`)、任意。NULL=起票時に選ぶ |
| `journal_template_group_id` | 所属グループ | FK(`journal_template_groups`)、任意。単一所属。NULL=未分類 |
| `sort_order` | 表示順 | 同じ入れ物の中での表示順 |
| `is_active` | 有効/無効 | |

**journal_template_lines**

| フィールド | 説明 | 制約 |
|---|---|---|
| `journal_template_id` | テンプレート | FK、ON DELETE CASCADE |
| `line_no` | 行番号 | 1以上、テンプレート内でユニーク |
| `side` | 借方/貸方 | `debit`/`credit` |
| `account_id` | 勘定科目 | FK、任意。NULL=科目がまだ決まっていない行(追加直後) |
| `amount` | 金額 | 任意。NULL=起票時に入力、または正の整数 |
| `project_id` | プロジェクト | FK、任意 |
| `household_member_id` | 世帯メンバー | FK、任意。NULL=行では決めない |
| `counterparty_id` | 取引先 | FK、任意。収益・費用の科目の行のみ(トリガー) |
| `settlement_batch_id` | 精算バッチ | FK、任意。立替金・未払金の行のみ(Repository) |

**journal_template_groups**

| フィールド | 説明 | 制約 |
|---|---|---|
| `id` | グループID | PK |
| `name` | グループ名 | 同じ親グループ内でユニーク(非アクティブは除外) |
| `parent_group_id` | 親グループ | FK(自己参照)、任意。NULL=最上位 |
| `sort_order` | 表示順 | サブグループと直属のテンプレートで1つの表示順を共有する |

子グループまたは所属するテンプレートがあるグループは物理削除できない(トリガーで強制)。
