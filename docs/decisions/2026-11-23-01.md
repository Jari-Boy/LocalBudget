## 2026-11-23: 画面上部の固定(タブ・絞り込み欄・一括編集バー・表の見出し)は、見出しの複製と CSS 変数で実現する(計画Issue #266)

**背景**: 縦に長い画面で、スクロールするとタブの行・絞り込み欄・一括編集バー・表の見出しが見えなくなり、列の意味や操作が分からなくなっていた。
**決定**:
1. **一括編集バーは、選んだときだけ出す**。領域を常に確保する案(A案)は、案内文が常に出て見た目が悪いため却下した。バーの出入りで行が動く分は、ページのスクロール補正(`useKeepRowsInPlace`)で相殺する。
2. **表の見出しは、枠の外に置いた複製(`FloatingTableHeader`)を固定する**。表を画面に収まる枠にして枠内スクロールにし、見出しを`sticky`にする案は、枠の端でページのスクロールに引き継がれて見出しが隠れ、使いにくいため却下した。横スクロール用の枠(`overflow-x: auto`)の中の`sticky`はページのスクロールでは効かないため、複製を枠の外に置く。複製は固定していない間は`aria-hidden`かつ`inert`。列幅は`colgroup`または本物の見出しから写す。固定する高さは`--sticky-head-h`・`--sticky-head-extra`・`--sticky-bulk-h`で一元管理する。
3. **絞り込み欄は共通部品`FilterToggleButton`で開閉する**。初期は閉、条件は閉じても保持し、件数バッジで絞り込み中と分かるようにした。
4. **固定する対象**: 仕訳一覧・明細取込・マスタの各タブ(検索・追加の行と表の見出し)・割勘/精算のタブと表の見出し・分析のタブ。**見送り**: 分析の条件バー、マスタのマッピングのプレビュー表と右パネル内の表、画面タイトル。
5. **明細取込の1ページ件数を100件から50件にした**(`IMPORT_PAGE_SIZE`)。計画Issue #263の項(6)で100件とした後の変更。
6. **テストでの注意**: 複製は`aria-hidden`だが、既存テストの`getByLabelText`が複製と本物の両方に一致して重複するため、テストは`getByRole`を使う。
**影響**: `src/components/common/sticky/`(`FloatingTableHeader`・`StickyHeaderTable`・`StickyToolbar`・`useElementHeight`・`useKeepRowsInPlace`)を追加した。`docs/architecture.md`(8章の固定要素の項)を更新した。
