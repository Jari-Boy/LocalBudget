## 2026-11-28: 仕訳の絞り込みに、期間の日付/月の切替・借方貸方別の条件・金額の範囲スライダーを足す(計画Issue #314)

**背景**: 仕訳の絞り込みは、期間が日付入力だけ、科目・取引先などが借方・貸方を区別できない、金額が数字入力だけだった。分析画面では期間を月/日付で切り替えられる。絞り込みの共通部品(`JournalFilterPanel`)は仕訳一覧・割勘・関連仕訳の選択で共有し、明細取込(`ImportRowFilterPanel`)は見た目だけを共有してモデルは別である。

**決定**:
1. **期間は、条件の値を`dateFrom`/`dateTo`のまま、入力だけを日付/月で切り替える**(`PeriodRangeInput`、`src/components/common/period-range/`)。分析画面と同じ「日付で指定」のチェックで切り替え、月は開始月の1日〜終了月の末日に変換する。仕訳の絞り込みは期間なしが普通の状態なので、月の選択肢に「指定なし」を置く。日付→月へ切り替えると含まれる月に広がる(範囲が変わるので、切替の時点で条件に反映する)。月の選択肢は絞り込む仕訳の日付から作る。仕訳一覧・割勘・明細取込で共有する。
2. **借方・貸方別の条件は、`JournalEntryFilter`に`debit`・`credit`(`JournalEntrySideFilter`)を足して持つ**(案A)。既存のまとめてのキーはそのまま残し、同じ形の入れ子の条件を足す。キーを平らに倍に増やす案(案B)は、軸を増やすたびに重複するので採らなかった。判定の中身は軸ごとの判定(`buildLineAxesMatcher`)に切り出し、まとめて・借方・貸方で共用する。判定は従来どおり仕訳単位で、軸ごとにその側の別々の明細行で満たしてよい。借方と貸方の両方を指定したらAND。対象は明細行ごとの属性の軸(科目・取引先・プロジェクト・世帯メンバー・精算バッチ)。出どころは仕訳単位の条件なので分けない。
3. **まとめて/分けるの切替は、パネル全体で1つの「借方・貸方を分けて検索」のチェック**にし、対象の5軸を緑の枠で囲んで範囲を示す。切り替えると、競合するもう一方の条件は消える(両方を持ち越すと、画面に出ていない条件が効き続けるため)。借方・貸方の条件を持つ条件で開いたときは、はじめから分けた状態で開く。分析画面から条件つきで仕訳一覧を開く経路は、まとめての条件を渡すだけなので変わらない。
4. **金額は、数字入力と2つ摘みのスライダー(`AmountRangeInput`・`AmountRangeSlider`、`src/components/common/amount-range/`)を1つの枠にまとめる**。標準の入力部品に2つ摘みが無いので自作した。目盛りは 0 / 1,000 / 1万 / 10万 / 100万 / 上限なし の非線形(等間隔)で、100万円より先は「絞り込む仕訳の最大金額(200万円を下限)」まで直線で補間し、右端は金額の上限を指定しない。数字入力と双方向に同期し、目盛りの範囲を超える入力値は摘みを端に寄せて表示しつつ値は保つ。ドラッグのほか、矢印・PageUp/PageDown・Home/Endで動かせ、摘みには`slider`の役割と値の読み上げを付ける。金額の意味(仕訳の借方合計)は変えない。
5. **明細取込には期間の切替だけを入れ、金額スライダーと借方・貸方の切替は付けない**。取込の金額の絞り込みは符号つき(支出はマイナス)の比較で、0以上の目盛りのスライダーと意味が合わない。金額の意味を変える(絶対値で比べる)案は、既存の仕様とテストを変えることになるので、ユーザーの判断で見送った。借方・貸方の概念は取込の行には無い。
6. 付随して、出どころの欄を摘要の隣に移し、「条件をクリア」をアイコンつきのボタンにした。一致科目の強調(`matchedAccountIdsOf`)は、側ごとの代表は持たず、まとめて・借方・貸方の科目の指定を合わせた集合を使う。

**却下した案**:
- 借方・貸方の条件を平らなキー(`debitAccountIds`など)で持つ: 軸を増やすたびにキーが倍になる。
- 切替で、まとめての条件を借方・貸方の両方へ写す: 「どちらかの側にある」を「両方の側にある」に変えてしまい、意味が変わる。
- 金額を線形のスライダーにする: 1円から数百万円に偏るため、少額の範囲がほとんど操作できない。

**影響**: `JournalEntryFilter`(`src/domain/journal/`)、`filterJournalEntries`、`journalFilterModel`(範囲 both/debit/credit の読み書き、`toSplitMode`・`toCombinedMode`、`buildEntryRangeOptions`)、`JournalFilterPanel`、`ImportRowFilterPanel`、`matchedAccountIdsOf`。新しい共通部品として`period-range/`・`amount-range/`を追加し、月の選択の`<select>`は固定の選択肢として生selectの許可一覧に加えた。
